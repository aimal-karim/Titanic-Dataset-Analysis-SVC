# Titanic Dataset Analysis & SVC Classification

## Project Description
This repository contains a step-by-step data analysis, feature preparation, visualization, and Machine Learning model implementation on the Titanic dataset using Python.

## Workflow
1. **Dataset Overview & Statistics**: Summarized numerical/categorical features and dataset shape.
2. **Data Cleaning**: Imputed missing numerical values using median imputation.
3. **Feature Scaling & Machine Learning**: Standardized independent variables using `StandardScaler` and trained a `Support Vector Classifier (SVC)`.
4. **Data Visualization**: Plotted class-wise survival rates, fare distributions, and gender survival counts using `Seaborn`.

## Project Structure
* `titanic_analysis.ipynb` — Complete Jupyter Notebook with code and outputs.
* `titanic.csv` — Dataset file.

## Tech Stack
* Python 3.x
* Pandas, NumPy
* Scikit-Learn (SVC, StandardScaler)
* Matplotlib, Seaborn
